# 콘텐츠 모드 (blog · threads)

위키·정보글은 깊이 분석과 점수표를 생략하고 독자의 질문, 답을 뒷받침하는 본문 근거, 제목 또는 첫 줄 후보를 정리한다. 글 전체를 맡겼다면 선택한 후보를 완성 초안에 반영한다. 경험 글의 양식은 다음과 같다.

```markdown
# Keyword & Title — {시드 요약 15자}

## 시드
{원문}

## 깊이 분석
- 만다라트 축: {1~8}
- Personal Depth: {0.0~1.0}
- 메타포: {시드에서 추출한 1줄}
- 반대축: {거부하는 것}

## 키워드 후보 ({N}개)
| 순위 | 키워드 | 사분면 | Viral Score | 핵심 신호 |
| ... |

## 블로그 제목 후보 / Threads 첫 줄 후보
- (결론형/이야기형/선택의순간형 또는 회고형/발견형)

## 자가 체크 / 다음 액션
```
