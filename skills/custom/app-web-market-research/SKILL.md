앱·웹서비스 리서치에서 시장 규모, 설치 수, 사용자 수, 사용량, 웹 트래픽, 마케팅 채널, 경쟁 구도를 확인하는 기본 워크플로우다.

## 먼저 읽을 문서

- `/home/ubuntu/workspace/knowledge-lab/source/openclaw-system/docs/research/APP_WEB_RESEARCH_STATS_SOURCES.md`

이 문서의 소스 목록과 지표별 우선순위를 기본값으로 쓴다.

## 트리거

사용자가 아래와 비슷하게 말하면 이 스킬을 사용한다.

- 앱 비교해줘
- 시장조사해줘
- 경쟁앱 분석해줘
- 이 서비스 시장 크기 봐줘
- 설치 수, 유저 수, DAU, MAU, 사용량, 체류시간 확인해줘
- 웹 트래픽이나 마케팅 채널 봐줘
- 이 앱이 잘 되는지, 얼마나 쓰이는지, 수요가 있는지 봐줘
- 그 나라에서 요즘 뜨는 앱, 트렌딩 앱, 순위 상승 앱 찾아줘

## 기본 원칙

- 최신 지표와 도구 정책은 변할 수 있으므로 웹 확인을 기본으로 한다.
- 무료 수치는 방향 확인용 추정치로만 쓴다.
- 절대값 하나로 결론내지 않고, 최소 3개 축을 같이 본다.
  - 시장 배경
  - 앱 다운로드/매출/랭킹
  - 웹 트래픽/검색 수요
  - 리뷰 불만/기능 공백
  - 마케팅 채널/광고 의존도
- 출처별 수치가 다르면 하나로 평균내지 말고 범위와 차이를 설명한다.
- 유료 도구 데모나 결제는 사용자 승인 전에는 진행하지 않는다.
- `트렌딩 앱`은 다운로드 증가 원자료를 못 볼 수 있으므로, 순위 상승·신규 상위 진입·리뷰 증가·검색량·커뮤니티 언급을 묶어 판단한다.

## 조사 순서

1. 요청 범위를 고정한다.
   - 앱인지 웹인지, 국가/언어권, 비교 대상, 목적을 확인한다.
   - 목적이 불분명하면 기본값은 `한국/글로벌 둘 다`, `무료 공개 자료 중심`, `아이디어 검증용`이다.

2. 시장 배경을 본다.
   - `DataReportal`, `Business of Apps`, `Statista`, 산업 리포트로 큰 시장 규모와 성장 방향을 잡는다.

3. 웹 수요를 본다.
   - `Similarweb`, `Google Trends`, 검색 결과, SEO 도구로 트래픽·유입 채널·검색 관심도를 확인한다.

4. 앱 경쟁을 본다.
   - `Similarweb App`, `AppMagic`, `Appfigures`, `AppTweak`, `MobileAction`, 앱스토어/구글플레이 원문을 확인한다.
   - 가능하면 다운로드/매출/랭킹/키워드/리뷰를 분리해서 본다.

5. 트렌딩 신호를 본다.
   - 국가별 앱스토어/구글플레이 상위권 신규 진입 앱과 순위 상승 앱을 확인한다.
   - 무료 공개 자료로 설치 증가량을 못 보면 `rank_change`, `new_in_chart`, `review_velocity`, `search_trend`, `community_mentions` 중 확인 가능한 신호만 쓴다.
   - `현재 인기 앱`과 `떠오르는 앱`을 구분해서 쓴다.

6. 원문을 직접 읽는다.
   - 앱스토어/구글플레이 설명, 스크린샷, 가격, 인앱결제, 업데이트 빈도, 리뷰 불만을 확인한다.
   - 리뷰 수로 설치 수를 역산할 때는 매우 거친 추정임을 밝힌다.

7. 결론을 낸다.
   - `시장 크기`, `성장 신호`, `트렌딩 앱`, `경쟁 강도`, `차별화 빈칸`, `초기 진입 추천 여부`, `다음 확인 자료` 순서로 압축한다.

## 출력 형식

짧은 리서치는 아래 형식으로 답한다.

```markdown
**결론**
...

**확인한 신호**
- 시장:
- 앱:
- 트렌딩:
- 웹:
- 리뷰/불만:
- 마케팅:

**판단**
- 기회:
- 위험:
- 다음 확인:

**출처**
- ...
```

숫자를 쓸 때는 가능한 한 아래 라벨을 붙인다.

- `official`: 회사/스토어/공시 원문
- `estimate`: Similarweb, Sensor Tower류 추정치
- `survey`: 설문/리포트 기반 통계
- `report`: 산업 리포트
- `store_raw`: 앱스토어/구글플레이 원문
- `trend_signal`: 순위 상승, 신규 진입, 리뷰 증가, 검색량 상승, 커뮤니티 언급 기반 판단

## 기본 소스

- `Similarweb`: 웹 트래픽, 유입 채널, 경쟁 도메인, 앱 사용량 일부
- `AppMagic`: 앱/게임 다운로드, 매출, 카테고리 흐름
- `Appfigures`: 앱 다운로드/매출 추정, 리뷰, 랭킹, ASO
- `AppTweak`: ASO, 키워드, 다운로드/매출 추정
- `MobileAction`: ASO, 키워드, 경쟁 앱 분석
- `Sensor Tower`: 유료급 앱 다운로드, 매출, DAU/MAU, 세션, 광고/ASO
- `Apptopia`: 유료급 앱 다운로드, 매출, 사용량, SDK, 경쟁 분석
- `DataReportal`: 국가별 인터넷·모바일·소셜 통계
- `Business of Apps`: 앱 카테고리별 통계와 시장 배경
- `Google Trends`: 검색 관심도와 시즌성

## 주의

- `Sensor Tower`급 앱 인텔리전스는 무료로 완전히 대체하기 어렵다.
- 무료 페이지가 막히거나 로그인이 필요하면 막힌 지점을 밝히고, 가능한 공개 출처만으로 판단한다.
- 사용자가 실제 투자/제품 방향 결정을 하려는 경우, 정확한 수치보다 `반복되는 방향성`과 `검증해야 할 가정`을 더 강조한다.
