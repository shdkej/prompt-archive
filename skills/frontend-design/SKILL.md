이 스킬은 흔한 "AI slop" 미학을 피하는 독창적이고 프로덕션급의 프론트엔드 인터페이스 제작을 안내합니다. 미적 디테일과 창의적 선택에 각별히 주의를 기울여 실제로 동작하는 코드를 구현하세요.

사용자는 프론트엔드 요구사항(제작할 컴포넌트, 페이지, 애플리케이션, 인터페이스)을 제공합니다. 목적, 대상 사용자, 기술적 제약에 관한 맥락이 포함될 수 있습니다.

## Design Thinking

코딩에 앞서 맥락을 이해하고 과감한(BOLD) 미적 방향에 전념하세요:
- **Purpose**: 이 인터페이스는 어떤 문제를 해결하는가? 누가 사용하는가?
- **Tone**: 극단을 택하세요: 극도로 미니멀, 맥시멀리스트 카오스, 레트로 퓨처리즘, 유기적/자연적, 럭셔리/세련됨, 장난스러움/장난감 같은, 에디토리얼/매거진, 브루탈리즘/날것, 아르데코/기하학적, 부드러움/파스텔, 인더스트리얼/실용적 등. 선택할 수 있는 결이 무수히 많습니다. 이를 영감으로 삼되 미적 방향에 충실한 디자인을 직접 만드세요.
- **Constraints**: 기술적 요구사항(framework, 성능, 접근성).
- **Differentiation**: 무엇이 이것을 잊을 수 없게(UNFORGETTABLE) 만드는가? 누군가 기억할 단 하나는 무엇인가?

**CRITICAL**: 명확한 개념적 방향을 택하고 정밀하게 실행하세요. 과감한 맥시멀리즘과 세련된 미니멀리즘 둘 다 통합니다. 핵심은 강도가 아니라 의도성입니다.

그런 다음 아래와 같은, 실제로 동작하는 코드(HTML/CSS/JS, React, Vue 등)를 구현하세요:
- 프로덕션급이며 기능적
- 시각적으로 강렬하고 기억에 남는
- 명확한 미적 관점으로 일관된
- 모든 디테일이 세심하게 다듬어진

## Frontend Aesthetics Guidelines

다음에 집중하세요:
- **Typography**: 아름답고 독특하며 흥미로운 폰트를 선택하세요. Arial이나 Inter 같은 일반적인 폰트는 피하고, 대신 프론트엔드의 미감을 끌어올리는 개성 있는 선택, 예상치 못하고 특징적인 폰트를 택하세요. 개성 있는 디스플레이 폰트와 세련된 본문 폰트를 짝지으세요.
- **Color & Theme**: 일관된 미학에 전념하세요. 일관성을 위해 CSS 변수를 사용하세요. 지배적인 색상에 날카로운 강조색을 더한 구성이, 소심하고 고르게 분배된 팔레트보다 낫습니다.
- **Motion**: 효과와 마이크로 인터랙션에 애니메이션을 사용하세요. HTML에서는 CSS만으로 된 해법을 우선하세요. React에서는 가능하면 Motion 라이브러리를 사용하세요. 임팩트가 큰 순간에 집중하세요. 잘 연출된 하나의 페이지 로드에서 시차를 둔 등장(animation-delay)은, 흩뿌려진 마이크로 인터랙션보다 더 큰 즐거움을 줍니다. 놀라움을 주는 스크롤 트리거와 호버 상태를 사용하세요.
- **Spatial Composition**: 예상 밖의 레이아웃. 비대칭. 겹침. 대각선 흐름. 그리드를 깨는 요소. 넉넉한 여백 또는 통제된 밀도.
- **Backgrounds & Visual Details**: 단색으로 기본 처리하는 대신 분위기와 깊이를 만드세요. 전체 미학에 맞는 맥락적 효과와 텍스처를 더하세요. gradient mesh, noise 텍스처, 기하학적 패턴, 겹쳐진 투명도, 극적인 그림자, 장식적 테두리, 커스텀 커서, grain 오버레이 같은 창의적 형태를 적용하세요.

남용되는 폰트 패밀리(Inter, Roboto, Arial, system fonts), 진부한 색 조합(특히 흰 배경 위 보라색 그라데이션), 뻔한 레이아웃과 컴포넌트 패턴, 맥락 특유의 개성이 없는 천편일률적 디자인 같은 일반적인 AI 생성 미학은 절대 사용하지 마세요.

창의적으로 해석하고 맥락에 진정으로 맞춰 디자인된 듯한 예상 밖의 선택을 하세요. 어떤 디자인도 똑같아서는 안 됩니다. 라이트 테마와 다크 테마, 서로 다른 폰트, 서로 다른 미학을 오가며 변주하세요. 여러 생성물에 걸쳐 흔한 선택(예: Space Grotesk)으로 수렴하지 마세요.

**IMPORTANT**: 구현 복잡도를 미적 비전에 맞추세요. 맥시멀리스트 디자인에는 광범위한 애니메이션과 효과를 갖춘 정교한 코드가 필요합니다. 미니멀하거나 세련된 디자인에는 절제, 정밀함, 그리고 간격, 타이포그래피, 미묘한 디테일에 대한 세심한 주의가 필요합니다. 우아함은 비전을 잘 실행하는 데서 나옵니다.

기억하세요: Claude는 비범한 창의적 작업을 해낼 수 있습니다. 주저하지 말고, 틀을 깨고 사고하며 개성 있는 비전에 온전히 전념할 때 진정 무엇을 만들 수 있는지 보여주세요.
